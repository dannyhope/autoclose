# What's New in Autoclose

Autoclose has had a busy few weeks. Here's what's changed to make managing your tabs easier.

## "White List" replaces "Safe URLs"

The list of URLs you want to auto-close is now called the **White List**. Same functionality, clearer name.

## Smarter URL Matching

Autoclose now handles tracking parameters better. When a site adds `?utm_source=newsletter` or similar tracking junk to your URLs, Autoclose can still recognise them as matches.

**Strict matching** is available if you need exact URL matches, but loose matching is now the default for more reliable tab closing.

## Import and Export Your List

You can now save your White List to a file and load it back later. Handy for:
- Backing up your list
- Moving to a new computer
- Sharing lists between browsers

Just click **Export** to download your list as a text file, or **Import** to load one.

## Better Feedback Link

Found a bug or have an idea? The feedback link now goes straight to GitHub Issues, where your suggestions can be tracked and addressed.

## What's Next

We're working on getting Autoclose into the Chrome Web Store for easier installation. Stay tuned.
